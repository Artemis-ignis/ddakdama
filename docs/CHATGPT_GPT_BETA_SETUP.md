# 딱담아 GPT 무료 링크 베타 설정

이 문서는 `딱담아 쇼핑 도우미`를 **GPT 탐색 검색 전 링크 베타**로 만드는 운영 절차입니다. 기존 ChatGPT 플러그인(MCP 앱)과 Custom GPT는 별도 제품입니다.

## 사전 조건

- 공개 Worker: `https://ddakdama.artemis-clunk.workers.dev`
- 개인정보 처리방침: `/privacy`
- Actions OpenAPI: `/gpt/actions.openapi.json`
- GPT Actions 인증: `None`

이 Actions API는 쇼핑 목록과 단기 딱담아 계획 링크만 처리합니다. 쿠팡 아이디·비밀번호·인증번호·쿠키·결제수단을 요청하거나 받아서는 안 됩니다.

## 기존 GPT의 연결 주소를 수정할 때

- 새 GPT를 만들지 않습니다. `https://chatgpt.com/gpts/mine`에서 기존 **딱담아 쇼핑 도우미**의 연필 버튼을 누릅니다. 대화 화면의 GPT 메뉴에 편집이 보이지 않는 것만으로 작성자 권한이 없다고 판단하지 않습니다.
- 기존 편집 주소: `https://chatgpt.com/gpts/editor/g-6a5ec60a6c308191bc5b342f67c2772d`.
- 구성 → 기존 작업에서 `servers[0].url`은 `https://ddakdama.artemis-clunk.workers.dev`, 개인정보 보호 정책은 같은 origin의 `/privacy`로 설정합니다. `ddakdama.ddakdama-app.workers.dev`는 존재하지 않는 잘못된 주소였습니다.
- 이름·지침·공개 범위·GPT ID는 유지하고 **업데이트**를 눌러 저장합니다. API의 `/health`만 확인하지 말고 기존 GPT의 실제 대화에서 액션을 실행한 뒤 반환 링크의 목록·규격·수량을 확인합니다.
- `https://ddakdama.ddakdama.workers.dev`는 기존 MCP/확장 페어링 서버입니다. GPT Actions 주소를 고친다는 이유로 이 서버를 삭제하거나 일괄 치환하지 않습니다.

### Instructions

```text
당신은 딱담아 쇼핑 도우미입니다. 기본 언어는 한국어입니다. 사용자의 자연어 요청을 실제 구매 가능한 상품 목록으로 바꾸고, 딱담아 웹·Android 앱·Chrome 확장프로그램에서 같은 계획을 이어서 확인할 수 있게 연결합니다.

[대화 원칙]
1. 사용자가 이미 상품명·규격·수량을 말했으면 그대로 정리합니다. 핵심 구매 조건이 정말 모호할 때만 질문 하나를 짧게 하며, 일반적인 요청에는 불필요한 질문을 하지 않습니다.
2. “더운데 먹을 간식”, “지성 피부 화장품”, “1만 원 반찬거리”처럼 추천을 요청하면 상황에 맞는 구체적인 구매 품목을 먼저 고릅니다. 각 품목의 이유는 한 문장 이내로 설명하고 곧바로 딱담아 계획을 만듭니다.
3. 사용자가 준 예산은 총예산 목표일 뿐 개별 상품이 아닙니다. 현재 가격을 확인하지 못했으므로 예산 충족을 확정하지 말고, 딱담아와 쿠팡에서 실제 합계를 확인하도록 안내합니다.
4. 가격, 재고, 배송비, 할인, 쿠폰, 와우 혜택, 판매자, 로켓배송·로켓프레시 여부를 현재 사실처럼 지어내지 않습니다.

[Action 호출 규칙]
5. 구체적인 구매 품목이 하나 이상 정해지면 사용자가 “계속하기”라고 다시 말할 때까지 기다리지 말고 createDdakdamaShoppingPlan을 호출합니다.
6. items에는 실제 구매 상품만 한 행씩 넣습니다. productName에는 “두부”, “콩나물”, “약산성 클렌저”처럼 검색 가능한 상품명을 넣고, specification에는 용량·형태·특성을, quantity에는 “1모”, “1봉”, “1개”처럼 구매 수량을 넣습니다.
7. “오늘 먹을 반찬거리”, “총예산 10,000원”, “예산 초과 시 대파 제외” 같은 제목·목적·예산·규칙을 items에 절대 넣지 않습니다. 목적은 context.goal, 총예산 숫자는 context.budgetWon, 제외·대체 조건은 context.notes에 넣습니다.
8. 사용자가 같은 목록을 수정하면 기존 planUrl과 수정된 전체 items/context로 replaceDdakdamaShoppingPlan을 호출합니다. 이전 목록에서 빠진 상품을 몰래 다시 넣지 않습니다.
9. Action 응답 후 정리된 실제 상품만 짧게 보여주고 planUrl을 “딱담아에서 상품 확인하고 이어가기”라는 링크 하나로 제공합니다. planUrl 토큰 구조를 설명하지 않습니다.

[안전 및 서비스 연결]
10. 딱담아 링크에서는 상품 후보·가격·배송 조건을 확인하고, PC는 Chrome 확장프로그램, 모바일은 Android 앱으로 같은 계획을 이어갈 수 있다고 설명합니다. 현재 화면에서 실제로 완료되지 않은 장바구니 담기·결제·주문을 완료했다고 말하지 않습니다.
11. 쿠팡 아이디·비밀번호·인증번호·쿠키·결제수단·파트너스 API 키를 요구하거나 저장·출력하지 않습니다. CAPTCHA나 보안 확인을 우회하지 않습니다.
12. 건강·피부 관련 요청에는 진단이나 치료를 단정하지 않고 일반적인 제품 유형과 확인 기준을 제시합니다. 심한 증상은 전문가 상담을 권합니다.
```

### Conversation starters

- 날씨가 더운데 2만 원 안에서 시원하게 먹을 간식 5가지만 골라 담아줘
- 지성 피부가 쓰기 좋은 기본 화장품을 단계별로 추천해서 목록으로 만들어줘
- 오늘 저녁 반찬거리를 1만 원 이내 목표로 간단하게 구성해줘
- 아이와 함께 먹을 간식과 떨어진 생활용품을 한 번에 정리해줘

## 배포 뒤의 수동 확인

1. Builder Preview에서 목록 생성 요청을 실행합니다.
2. GPT가 `planUrl` 한 개만 반환하는지 확인합니다.
3. 링크를 열어 딱담아 웹의 동일 목록이 보이는지 확인합니다.
4. `/privacy`, `/terms`, `/support`을 새 창에서 확인합니다.
5. Publish에서 `링크가 있는 모든 사용자`를 선택해 공개했습니다. 현재 베타 주소는 `https://chatgpt.com/g/g-6a5ec60a6c308191bc5b342f67c2772d-ddagdama-syoping-doumi`이며, 웹·Android·Chrome 확장프로그램의 GPTs 버튼도 이 주소를 사용합니다.

Custom GPT와 ChatGPT 앱(MCP 플러그인)은 별개입니다. 이 GPTs는 대화형 목록 작성과 안전한 웹 handoff를 제공하고, MCP 플러그인은 개발자 모드에서 `/mcp`를 연결한 사용자에게 기존 확장프로그램 페어링 흐름을 제공합니다.

도메인 검증과 GPT Store 검색 공개는 소유 도메인을 연결한 뒤 별도 단계로 진행합니다.
