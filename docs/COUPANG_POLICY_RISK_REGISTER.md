# 쿠팡 정책 및 실적 위험 등록부

| 위험 | 현재 상태 | 출시 전 조치 | 완료 근거 |
| --- | --- | --- | --- |
| 파트너스 딥링크 실적 인정 | 미검증 | 실제 키와 정상 제3자 테스트 주문으로 확인 | Partners report에서 해당 `affiliateSubId`의 클릭·주문이 일치하는 화면 기록 |
| 모바일 WebView 장바구니 자동화 허용 | 미확인 | 쿠팡에 서면 문의, 공개 전 feature flag 유지 | 기능 범위·장바구니만 자동화·결제 미자동화가 명시된 쿠팡 답변 |
| 배송비·쿠폰·와우 혜택 | 사용자 조건 의존 | 서버에서는 `UNKNOWN`, 쿠팡 장바구니에서 재확인 | 서로 다른 배송지·와우 상태에서 장바구니 `CartSettlementSnapshot` 비교 |
| DOM 변경 | 상시 위험 | fixture E2E와 product ID·가격·수량 delta 검증 유지 | 로그인된 실기기에서 상품 ID·옵션·장바구니 delta 수동 검증 기록 |
| 사용자 신뢰 | 중요 | 제휴 고지와 일반 URL fallback을 명확히 표시 | 실제 앱·웹·확장 UI 캡처에서 제휴/일반 링크 상태와 고지 확인 |

`REAL_COUPANG_AUTOMATION_ENABLED`는 위의 첫 두 항목과 실기기 장바구니 delta 근거가 모두 갖춰지기 전에는 `false`를 유지한다. fixture 결과, API 응답 성공, 일반 쿠팡 링크 이동은 이 근거를 대체하지 않는다.
